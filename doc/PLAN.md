- 게임 시스템 구조 :
1. 햄버거 조립 :
	
	조리대에서 햄버거 조립 가능
	재료 클릭 -> 자동으로 조립
	음식 드래그 & 드랍 -> 전달
2. 손님 시스템 :
	
	테이블 (최대 3인)에서
	랜덤한 햄버거 조립방식을 요구
	정해진 시간내()로 전달하지 못하면
	목숨 -1
3. 점수 시스템 :
	
	손님에게 제한시간내 햄버거 전달시 점수획득
4. 목숨 시스템 :
	
	최대 5
	목숨이 0이되면 게임오버
